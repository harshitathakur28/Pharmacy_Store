# MediCart Pharmacy Store

A full-stack pharmacy store app: React (Vite) client, Express/MongoDB API server.

- `client/` — React frontend, deployed to **GitHub Pages**
- `server/` — Express + MongoDB API, deployed to **Render**

## Local development

```bash
npm run install:all
cp server/.env.example server/.env   # fill in MONGO_URI and JWT_SECRET
npm run dev                          # runs client (5173) + server (5002)
npm run seed                         # optional: seed demo medicines + users
```

## Deployment

### 1. MongoDB (Atlas)

Create a free cluster at [MongoDB Atlas](https://www.mongodb.com/atlas), create a database user,
allow network access from anywhere (`0.0.0.0/0`) so Render can connect, and copy the connection string
(`mongodb+srv://...`).

### 2. Backend (Render)

This repo includes a `render.yaml` blueprint.

1. On [Render](https://render.com), **New → Blueprint**, connect this repo.
2. Render detects `render.yaml` and creates a web service rooted at `server/`.
3. Set these environment variables on the service:
   - `MONGO_URI` — your Atlas connection string
   - `CLIENT_URL` — `https://harshitathakur28.github.io` (add more, comma-separated, for local dev)
   - `JWT_SECRET` is auto-generated by the blueprint; `JWT_EXPIRES_IN` defaults to `7d`
4. Deploy. Note the resulting URL, e.g. `https://pharmacy-store-api.onrender.com`.

Without the blueprint: create a Web Service manually, root directory `server`, build command
`npm install`, start command `npm start`, and set the same env vars.

### 3. Frontend (GitHub Pages)

1. In the GitHub repo, go to **Settings → Pages → Source** and select **GitHub Actions**.
2. In **Settings → Secrets and variables → Actions → Variables**, add a repository variable:
   - `VITE_API_URL` = `https://<your-render-service>.onrender.com/api`
3. Push to `main` (or re-run the workflow manually). `.github/workflows/deploy-pages.yml` builds
   `client/` and publishes it to Pages automatically.
4. The site will be live at `https://harshitathakur28.github.io/Pharmacy_Store/`.

If you rename the repo, also update `base` in `client/vite.config.js` to match the new path.
